Open Source & Free: The source code is free for anyone to view, modify, and redistribute.
Linux Kernel: The core component that manages system resources, including CPU, memory, and devices.
Distributions ("Distros"): Because Linux is just a kernel, it is combined with software libraries and tools to create a functional OS, known as a distribution (e.g., Ubuntu, Fedora, Debian, Mint).
Ubiquity: Linux powers nearly all of the world's top 500 supercomputers, over 60% of web servers, and countless IoT devices.
Interface: Users can interact with Linux via a command-line shell (terminal) or various graphical user interfaces (GUIs) like GNOME or KDE.
Security & Performance: It is renowned for high reliability and, in many cases, superior performance over proprietary systems.
